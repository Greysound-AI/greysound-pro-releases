## Greysound Pro 0.1.21

- Improved Linux installation and startup reliability. Debian-family users can now install a native `.deb` package that automatically pulls in required system components, while the AppImage no longer requires FUSE 2 and provides actionable guidance when WebKitGTK is missing.
- Fixed audio-region fade changes sometimes failing to reach the desktop audio engine.
- Fixed desktop session restoration so region loops, saved timeline selections, and millisecond-accurate playhead positions are preserved correctly.
- Fixed recording-latency restoration so automatic compensation remains distinct from an intentional zero-millisecond override.
- Made timeline autoscroll follow manual playhead movement: keyboard nudges use playback-style page flips, while mouse dragging scrolls continuously near the timeline edges.

# Greysound Pro 0.1.31

A fix-focused update: adding stems to a session works on Linux, a failed "Add to session" now tells you what went wrong instead of quietly disappearing, the Linux window no longer shows two title bars, and CoProducer's chat behaves better while it works.

### CoProducer
- "Add to session → As stems" works on Linux. Previously it charged credits, showed "Downloading audio…" for a while, then vanished with no tracks. Linux lacked an MP3 decoder, so the first stem failed as soon as it was downloaded. MP3 is now decoded on Linux, which also fixes importing MP3 files and the Stem Split panel there.
- When adding audio to a session fails for any reason, on every platform, you now get a "Couldn't add audio to session" message with the reason, instead of a spinner that disappears. Partially added tracks are rolled back.
- Scrolling up while CoProducer is replying now reliably stops the chat from following the reply, whether you use the mouse wheel, trackpad, scrollbar, keyboard or touch. It follows again once you scroll back to the bottom or send a message. Previously a small scroll-up was often ignored and the view could snap back down mid-read.
- While waiting for a reply with Thinking mode off, the chat shows pulsing dots instead of the word "Thinking", which wrongly suggested reasoning was happening. Thinking mode on still shows the "Thinking" shimmer.
- The "Thinking" and tool-use shimmer no longer blanks out its label partway through each animation cycle.

### Linux
- The window no longer shows both the system title bar and the in-app title bar with duplicated minimize, maximize and close buttons. Only the in-app bar is drawn, and maximize and restore go through the window manager so they stay in sync.

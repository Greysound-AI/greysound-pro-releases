# Greysound Pro 0.2.0

Greysound Pro is now in beta, with downloads and updates from greysound.ai, FX Designer and the samplers working again, and session files that follow your renames.

### Downloads and updates

- Download Greysound Pro from [greysound.ai/pro](https://greysound.ai/pro): a universal .dmg for macOS, a Setup installer for Windows, and an AppImage for Linux (x86_64 and aarch64). Only the current version is offered.
- Updates are now checked for and downloaded from greysound.ai. Installing this version is all you need to do; future updates arrive in the app as before.

### Fixes

- FX Designer applies the effect chains it designs again. Since 0.1.27 it could describe a chain but show "Could not apply the proposed FX chain."
- Choosing a Drum Sampler kit or an Instrument Sampler instrument takes effect again, from the mixer and from the plug-in's own window.
- Renaming a session also renames its session file on disk, so the folder no longer keeps a copy under the old name.

### Layout and Settings

- Your credits, Settings, and account menu now sit at the bottom of the left rail in the DAW.
- Buttons and menus in the Settings window stand out more clearly from the background.

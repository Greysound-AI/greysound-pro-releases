# Greysound Pro 0.1.28

A workflow and polish update: precise editing tools that mirror Pro Tools (nudge, quantize, adjustable selections), a reworked plugin menu, a refreshed CoProducer panel, and a window that no longer resizes between the session picker and the DAW.

### Window & app
- The session picker and login screens now open in the same full-size window as the DAW, so opening a session no longer resizes or moves the window. The picker itself keeps its familiar size and position, centred in the workspace.
- New splash screen with boot status and the running version.
- Greysound Pro now runs one session at a time, like Pro Tools and Ableton. Double-clicking a `.gss` file while the app is running opens it in the running window (after asking to save if the current session has unsaved changes) instead of launching a second copy on Windows or doing nothing on macOS.
- New unified title bar across macOS, Windows, and Linux: the session name sits in the centre (click it to rename; it shows the unsaved dot, saving spinner, and sync status), the credit balance sits on the right, and Windows and Linux get proper minimize / maximize / close buttons. macOS keeps its native traffic lights and menu bar.
- A new app icon for macOS 26 that renders correctly with Liquid Glass; older macOS versions keep the previous icon.

### Editing
- Time selections can now be adjusted after they're made. Drag either end of the selection in the ruler to resize it; the resize cursor appears on both edges. Previously the first drag had to be perfect.
- Nudging now works the way Pro Tools users expect: a nudge value menu next to the grid value sets exactly how far the arrow keys move. With regions selected, the arrow keys nudge the regions; with a time selection, they nudge the selection; otherwise they move the playhead. The old behavior, where the step silently changed with zoom level, is gone.
- Quantize shortcuts under every keyboard scheme: Quantize to Grid snaps selected regions (or selected piano-roll notes) to the session grid, Quantize Selection re-applies your last quantize settings, and a third shortcut opens the quantize settings. Quantize settings are now remembered between sessions. An empty selection shows a message instead of doing nothing.
- The grid value menu in the toolbar is more compact and shows proper note icons instead of text glyphs that rendered as the same symbol for every value.
- Fixed piano-roll editing in narrower windows: double-clicking created notes on the wrong pitch or half a beat away from the click, and dragged notes didn't snap. The piano roll now also snaps to the session grid from the toolbar rather than a zoom-dependent grid.
- Clicking on the timeline while playing now relocates the playhead seamlessly. A click with a tiny bit of pointer movement no longer turns into an accidental time selection with the smart tool.
- Scroll-wheel and trackpad zoom no longer miscounts steps, jumps to maximum zoom, or goes dead at full zoom-out, and it now stays anchored under the cursor. The Pro Tools keyboard scheme also gains Pro Tools' wheel behavior.

### Undo
- Undoing a region move or trim now restores neighboring regions that the move had truncated, across drag, nudge, quantize, and group moves. Previously the moved region returned but the neighbor stayed cut.
- Undoing a move that broke a crossfade now brings the crossfade back instead of leaving a plain butt joint.

### Plugins
- The insert menu is reorganized by plugin type using Pro Tools' categories (EQ, Dynamics, Reverb, Delay, and so on) plus Greysound's AI and Amp, then by manufacturer with Greysound first, then plugin. A search box at the top matches across plugin name, manufacturer, and category. Plugins that declare several categories appear under each.

### MIDI
- Arming an instrument track whose MIDI input can't be connected now shows a warning immediately instead of staying silent until you press Record.
- Changing the preferred MIDI input device now re-routes armed and input-monitoring instrument tracks right away, so the new controller works without re-arming.

### CoProducer
- The chat panel has a cleaner layout: your messages appear as right-aligned bubbles, CoProducer replies run full width, activity rows shimmer while work is in progress, and each reply has a copy action.
- While CoProducer thinks you now see short progress labels such as "Reviewing the arrangement" instead of raw reasoning text, followed by "Thought for N seconds" with the label trail.
- Fixed thinking blocks showing "Thought for 0 seconds" after reopening a chat.

### Keyboard shortcuts
- Shortcuts are now driven by one definition per scheme, so the shortcuts dialog always matches what the keys actually do and conflicting bindings are caught before release. The Logic scheme's virtual keyboard toggle moves to Cmd+K, and the Ableton scheme adds M and Shift+C.

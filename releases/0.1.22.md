## Greysound Pro 0.1.22

- Fixed the Linux app failing to open its interface on systems where WebKitGTK was already installed through the normal system packages, which previously left a blank window or an incorrect prompt to install a component that was present.
- Added one-click installation of the WebKitGTK system component on Linux when it is genuinely missing, replacing the previous instruction to run a terminal command.
- Simplified the Linux download to a single AppImage with built-in automatic updates.

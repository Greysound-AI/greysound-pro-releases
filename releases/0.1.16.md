## Greysound Pro 0.1.16

- Improved responsiveness and reliability in plug-in-heavy sessions, including faster loading, saving, insert management, session duplication, and Library workflows.
- Improved preservation of third-party plug-in settings across reopening sessions, undo and redo, track copies, session duplication, and Library sync.
- Fixed an issue on macOS where an unreadable existing project could appear to open as an empty session instead of reporting the problem.
- Fixed plug-in-heavy sessions incorrectly appearing modified immediately after loading, along with session switches that sometimes required a second attempt.
- Added consistent unsaved-work protection when switching sessions, creating or importing projects, opening project files, and quitting the app, with options to save, discard, or cancel.
- Fixed generated audio downloads and uploads on Linux, allowing AI-generated audio to be added to sessions and committed as stems on both x86_64 and arm64 systems.
- Improved failed-download handling so incomplete files are not treated as successfully saved audio.
- Replaced production browser context menus with Greysound's in-app menus, including a Copy text action when selecting CoProducer chat text.
- Added a Greysound Pro information dialog to the session picker showing the installed version and controls to check for and install updates.

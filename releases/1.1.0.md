# Greysound Pro 1.1

Plug-ins that stay in their slots, Pro Tools-style routing and recording, a fuller Preview for automation, and a faster, steadier app, with many fixes for Windows.

### Plug-ins

- A plug-in that cannot load, because it is not installed, still scanning, or blocked, stays in its slot as an inactive insert. It shows the plug-in's name in italics and says why it is unavailable. The track's sound passes through unchanged, its settings and automation are kept and saved, and it becomes the plug-in again when a scan or Retry makes it available. Click it for a menu with Remove.
- The splash screen offers "Continue in the background" when the plug-in scan runs long. Opening a session or the insert menu during a scan tells you the list is not complete yet.
- Cancel a Rescan from Settings > Plug-ins, which is now also available on the start screen. A scan you quit in the middle resumes where it stopped.
- A plug-in is skipped at launch only after it fails in two runs in a row. Each blocked plug-in has a chevron that explains why, including plug-ins built for Intel Macs only. A blocked plug-in whose file was updated is scanned again.
- A plug-in whose editor crashed Greysound opens its editor only when you choose Open Anyway the next time.
- On the Mac, the scan skips the Waves and Native Instruments plug-ins the host refuses to load. On Windows, the scan keeps only the newest WaveShell of each major version.
- Plug-in scans no longer freeze the window at launch.

### Routing and recording

- Choosing a track under Output > Tracks routes through a bus, as in Pro Tools. A bus is a connector rather than a track. A track that records a hardware input is not offered as a destination; set its input to No Input first.
- Sessions saved before this version open as saved, with one notice about the new monitoring rules.
- A track whose input is a bus or another track is heard only as Pro Tools' Auto Input, and several tracks can record one source. A track with No Input or No Output cannot be record-enabled.
- A send or output that would feed back is refused with a plain sentence, in Session Settings, I/O Settings and send slots alike.
- Session Settings can set Audio Input to None where the audio driver allows it. Buffer Size and Low-Latency Monitoring now apply with Apply, so Cancel leaves them alone.
- Each take's live waveform is drawn from its own source. Audio clips play on their exact timeline samples.

### Automation

- Preview works more like Pro Tools. Option-click (Alt-click on Windows) isolates every write-enabled control, with Shift for the selected tracks. Command-click (Control-click) suspends Preview. Preview lights green, and the track's mode indicator lights while controls are isolated.
- Write to Start, All, End and Punch extend previewed values and keep Preview on. Punch Preview sets Latch and writes from the preview value.
- In a writing mode, faders and pans move while the transport is stopped, and a stopped move that Preview holds is kept when you play.

### Clips and stems

- Time Stretch and Pitch Shift in Pro now use Rubber Band, with a Quality choice of High quality or Fast. The CoProducer can pick the quality too.
- Invert Phase and Time Stretch show progress and can be cancelled in the web app as well.
- A stem split that loses its connection recovers instead of failing with "Failed to fetch", and is charged once.

### Sessions and saving

- A session no longer shows as unsaved after opening a plug-in editor, moving the playhead, loop or time selection, changing the time format, or undoing every edit back to the saved state.
- A reopened session comes back with the playhead, loop and scroll position it was left with. Quitting a large session saves its view state at once.
- New Session, My Sessions and Import Session are unavailable while a bounce runs. A finished bounce's temporary render is deleted.
- Selecting many files to import no longer silently does nothing.
- In the web app, a clip whose upload fails keeps its region, offers a retry, and survives a reload in that browser. Back or Forward away from an unsaved session asks first.

### CoProducer

- Long chats and large tool results save reliably, and a reply that finishes while the page is in the background keeps its last words.
- Undoing a Replace puts back the source clip with its crossfades. Routing and plug-in tools describe inactive inserts and "None" correctly.

### Faster and steadier

- Opening a large session is faster, and the window stays responsive while it loads. Leaving one is faster too.
- Dragging clips, playing with meters running, and multi-file imports use much less work per update.
- Editing regions, Invert Phase, Time Stretch and exports no longer hold up the rest of the app.
- Calls that take long no longer fail with a timeout while Pro is still working.

### Windows

- Changing the buffer size while Windows Audio is playing no longer stops the audio for most of a second, and switching the driver type no longer freezes Session Settings. A driver type whose device does not open goes back to the previous one and says why.
- Drag a plug-in, MIDI Editor or Automation window by its header to move it. A plug-in window opens inside the screen, and a fixed-size editor too large for the screen is drawn smaller to fit.
- Quitting no longer hangs on some plug-ins (Dexed hung File > New Session and quit), and minimising Pro no longer reloads the page to the session picker.
- The main window no longer flashes black, white and grey behind the splash at launch.

### Look and feel

- The bottom panel's Mixer, Plugins and Sends tabs are now labelled with text instead of icons.
- Notices are matte dialogs that keep their buttons in view in a short window, and Session Settings fits short windows.
- Error messages no longer mention internal names.

# Greysound Pro 1.1.1

A fix for Pro closing right after it starts on some Windows PCs, a CoProducer that no longer stops without an answer, and fixes for plug-in windows and dialogs.

### Windows

- Pro no longer closes a second or two after it starts on PCs with an older Visual C++ runtime. The installer now carries everything Pro needs, including the WebView2 Runtime, so there is nothing to install by hand. The FX Designer installer does the same.
- A dialog or menu opened after a plug-in window is no longer hidden behind it. Clicking in a plug-in's editor brings its window back to the front.
- A plug-in window takes the keyboard when it opens, including Surge XT and OB-Xf.

### CoProducer

- When your credits run out in the middle of a request, CoProducer ends with a short summary of what it changed and what is left, instead of stopping without a word. The summary is free.
- A reply that goes silent is ended after a few seconds and tried again, instead of hanging for minutes.
- Fewer replies end without an answer when a model is busy.
- CoProducer can move a clip to another track.
- A question about how the mix sounds is answered from loudness and frequency measurements of your tracks, in Ask mode too. A question about what a part is playing is answered by listening to it.
- Long chats keep their summary between requests, so later replies start sooner.

### Dialogs

- Escape closes only the dialog on top, and a panel with its own Escape action keeps it.
- Settings opened over a notice is drawn on top of it, and a click in a notice no longer reaches the dialog under it.

### Audio and MIDI

- Only the inputs the audio device actually opened are enabled, which removes wasted work on devices that list many channels.
- In the web app, a controller or pitch bend played just before Stop stays in the MIDI take.

### Faster and steadier

- The end of a plug-in scan no longer holds up the window.
- Paste, trim, split, recording, import and Replace are faster in large sessions.
- The four transport buttons have tooltips.

### Linux

- Under GNOME, the main window fills the work area instead of covering the top bar and dock.
- Started without a usable display, Pro exits with a message instead of crashing.

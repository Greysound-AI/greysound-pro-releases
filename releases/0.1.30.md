# Greysound Pro 0.1.30

A workflow and reliability update: scroll to adjust almost any knob, fader, or slider; covers now come out at the tempo and key you asked for; and a long-standing plug-in bug that made Reaktor 6 multiply across the insert menu and could poison a saved session is fixed at the root.

### Editing & UI
- Hover a knob or slider in any insert or plug-in window and scroll to adjust it. Hold Shift for fine adjustment. Stepped controls (note values, arp rates, integer parameters) step cleanly even with slow trackpad scrolling.
- The BPM readout now responds to scrolling and to press-and-drag up or down. A plain click still opens the text editor. Changes go through the engine and are undoable like any other tempo edit.
- Scroll anywhere on the Waveform Size, Timeline Zoom, and Section Navigate sliders to move them.
- Mixer volume faders, compact volume knobs, and per-channel pan knobs respond to scrolling too, with the same undo and automation behaviour as dragging.
- The "+" Add Track button now has a tooltip.
- "Apply to Session" in the Detect key and tempo dialog now sticks. Previously the ruler and regions updated to the new tempo but the first press of the spacebar snapped it back to the old value. The change is now undoable as well.

### Plug-ins
- Plug-ins are now identified by their class rather than by their bundle file. Bundles that export several plug-ins (Reaktor 6's instrument and effect, mono/stereo variants, WaveShell) previously shared one identity, which listed Reaktor 6 twice, leaked a "Reaktor 6" row into every other manufacturer's submenu on each hover, and could silently load the wrong class when restoring a session.
- Existing sessions saved with the old identity keep loading and now resolve to the correct class, using the saved class ID and the track type as hints.
- Same-name siblings in the insert picker are labelled "(Instrument)" or "(Effect)" so you can tell them apart.
- A failed plug-in class no longer hides its siblings from the picker for the rest of the session.

### CoProducer
- Cover Assist now has Target tempo and Target key controls, prefilled from the song lookup. Covers were previously rendered at the session's tempo and key (120 BPM, C major on a fresh session) no matter what the prompt said.
- When a cover's target differs from the session, the panel says so and offers "Set session to match". Committing a cover into an empty session asks whether to set the session tempo and key to match.
- CoProducer can now set the key signature, and on an empty session it sets tempo and key before generating.
- Describe Audio measures tempo and key from the audio itself before asking the model, so its answer agrees with Detect key and tempo. Values are labelled "(estimated)" when a measurement was not available.
- Messages you send now show their timestamp on hover right away instead of only after a reload.
- Fixed a CoProducer failure where replies came out as the model's private reasoning ending in a literal "</think>" and then generation stopped. The affected model routes are pinned to their intended upstream, and any already-affected chat recovers on its next message.

### Sessions & sign-in
- Deleting the last region in a session, or an autosave landing between a delete and a re-add, no longer triggers a "refusing to save an empty session" warning.
- The "Offline, using saved sign-in" notice has moved beneath the Log out button with an info icon so it no longer overlaps it.
- A saved sign-in that belongs to a different Greysound project now signs you out cleanly instead of showing a false offline state.

# Greysound Pro 0.1.27

A performance and reliability update fixing the three biggest issues reported on 0.1.26: runaway CPU/GPU usage, autosave freezing the interface, and Cut/Copy/Paste shortcuts not working.

### Performance & stability
- Fixed Greysound Pro pinning the CPU and GPU (and running the fans) even while idle. Audio clips carrying ACID loop metadata could silently spin the engine in a processing loop — those clips now play normally, and the runaway load and the multi-minute "Application not responding" hang when quitting are gone with it.
- Sessions can now be opened from anywhere on disk, not just the default Sessions folder.

### Saving
- Autosave no longer freezes the interface. Saves used to briefly halt everything — dragging, typing, playback UI — every time the autosave indicator fired; saving has been rebuilt to run off the interface thread and is now dramatically faster, so you shouldn't notice it happening at all.
- Autosave now waits until you finish what you're doing: it never fires in the middle of a drag or while you're typing, and rapid edits are gathered into a single save.
- Fixed sessions being marked as having unsaved changes the moment they were opened, which triggered a pointless save on every session open.
- Sessions stored outside the default folder now autosave correctly instead of failing with an "outside Greysound data directories" error.
- Creating a session with "Custom location" now actually creates it in the folder you pick (it was silently using the default location).

### Editing & clipboard
- Cut, Copy, Paste, and Select All keyboard shortcuts (Cmd+X/C/V/A) now genuinely work on regions in Greysound Pro. 0.1.26 claimed this fix but the embedded browser was still intercepting the keys before they reached the app; that interception has been removed at the source.
- Fixed undo after Cut or Delete: undoing now restores exactly the regions that were removed (previously it could appear to do nothing, and repeated undos would then unwind unrelated edits), and redo works symmetrically.
- Copy and paste now carry the whole sound of a region: clip gain always travels, fades travel when the copied range contains them, and crossfades travel when you copy the whole junction. Pasting several regions is a single undo step.
- Fixed playback resuming from the copy source instead of the clicked position after a copy → click → paste sequence.
- Crossfades on Pro now render and behave symmetrically on both sides of the junction.
- Clicking a region places the playhead at the region's start again (0.1.26 moved it to the exact click point; that change is reverted).

### CoProducer
- Cover-assist preprocessing was migrated to a new model for better results.

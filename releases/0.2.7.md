# Greysound Pro 0.2.7

A fix release for Greysound Pro on Linux, where sessions with stems or other non-English text could stop saving, plus a single-step undo for deleting several tracks.

### Fixes

- On Linux, Greysound Pro saves sessions again after you add stems. Stem names contain a dash that the Linux app could not pass to its file system, so the save never finished. File > Save stayed greyed out, Auto-Save stopped, Save & Continue froze, and the stems were missing after a restart. Any text outside plain English letters, such as accented names, curly quotes, or emoji in a track or clip name, had the same effect.
- On Linux, generation requests whose prompt contains such text no longer time out.
- If a save can't finish within 30 seconds, Greysound Pro now shows the save error instead of waiting forever. File > Save becomes available again, Auto-Save tries again, and the unsaved-changes dialog stays open so you can cancel or discard.
- Track > Delete with several tracks selected is now a single undo step.

# Greysound Pro 0.1.32

A Linux fix: menus, tooltips and the CoProducer chat header are readable again.

### Linux
- Dropdown menus, context menus, tooltips and the chat header now draw their frosted-glass background as they do on macOS and Windows. Previously these surfaces were rendered as a faint see-through tint, so their text landed directly on top of whatever was beneath and was hard to read. The embedded browser was being held in software rendering, which never paints the blur; it now uses hardware compositing.
- On machines where the graphics driver cannot provide hardware compositing, those surfaces fall back to a solid dark background instead of the see-through tint.

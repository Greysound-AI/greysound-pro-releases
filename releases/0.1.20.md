## Greysound Pro 0.1.20

- Added reliable timeline drag and drop for audio and MIDI files on Windows and Linux.
- Added system-wide Greysound project file support on Windows and Linux, so projects can be opened directly from the desktop or file manager across all supported platforms.
- Improved audio recovery on macOS after sleep or wake, including clearer recovery feedback and better preservation of playback position.
- Improved startup reliability on Linux, especially on clean installations, with clearer guidance when required app components are unavailable.
- Improved plug-in scanning reliability and made troubleshooting information easier to copy when a scan fails.
- Made plug-in formats easier to identify in the insert picker and added guidance and rescan controls for finding missing plug-ins.
- Expanded the timeline zoom range and made the full range available from the zoom slider.
- Refreshed Stem Separation with a cleaner, more consistent file-selection and results experience.
- Added an About section to Settings with the installed Greysound Pro version and controls to check for and install updates.

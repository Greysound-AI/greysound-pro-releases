# Greysound Pro 0.2.8

A fix release: sessions that would not open in Greysound Pro now open, MP3 files work on every Windows edition, Firefox playback is fixed, and session pages on the web load faster.

### Fixes in Greysound Pro

- A session that contains a send to a track that no longer exists now opens. Before, that one send stopped the whole session from loading. The send is listed in the notice that tells you part of the session didn't load, and it is kept in the session file rather than deleted.
- Deleting a track now also deletes other tracks' sends into it, as on the web, so the session no longer saves sends that point nowhere.
- Undoing the deletion of several tracks that send to each other now brings every track back.
- If your audio interface can't run at the session's sample rate, Greysound Pro now opens the session at the interface's own rate and shows the sample rate mismatch notice, instead of failing to open the session. If the audio device can't be opened at all, the error now says why.
- On Windows editions without Microsoft's media components (Windows N and KN without the Media Feature Pack), MP3 files, including AI vocals and stems, now preview, import, and play.
- When an AI audio preview can't start, Greysound Pro now tells you, and the play button returns to its normal state.
- During Rescan Plugins, plug-ins that the scan hasn't reached yet can still be loaded. If you cancel the rescan, your plug-in list stays complete.

### Fixes on the web

- In Firefox, Stop works again while a loop is playing, and gain changes in the Utility, Limiter, and Compressor plug-ins take effect.
- Session pages load faster.
- Changing your username while offline now shows an error instead of spinning forever.
- The Instrument Creator preview plays again after the browser has closed its audio.

### Fixes on both editions

- Some keyboards, including iPad keyboards, and browser autofill send key presses without a key name. These no longer cause errors, and the next key you press works as usual.

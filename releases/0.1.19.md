## Greysound Pro 0.1.19

- Added full track automation modes, including Off, Read, Touch, Latch, Touch/Latch, and Write, with improved automation writing, playback, editing, and session compatibility.
- Improved automation feedback throughout the DAW with responsive mixer controls, visible lane labels, formatted point values, and better-positioned menus.
- Improved playback and export consistency, including cleaner playback restarts and more complete effect and instrument tails in exported audio.
- Improved CoProducer reliability during long or interrupted tasks, with clearer recovery options, better validation, and more useful progress and error feedback.
- Improved recording reliability, live waveform alignment, take finalization, and storage of recorded audio within the active session.
- Improved audio-device setup and switching, including clearer preparation feedback, more reliable input routing, and better support for wireless and split input/output configurations.
- Improved audio and MIDI importing from file choosers and timeline drag and drop, with clearer track compatibility choices and more consistent placement feedback.
- Updated overlapping-region behavior so newer audio and MIDI regions take precedence while preserving unaffected material.
- Improved AutoVox and other AI audio workflows with native recording, file selection, previewing, uploading, downloading, and session placement.
- Improved waveform availability for newly generated, imported, copied, edited, and restored audio, including more reliable undo and redo.
- Improved session duplication so Greysound opens the completed copy, protects unsaved work, and keeps the original session separate.
- Added in-app password changes for supported accounts through the Account panel.
- Improved third-party plug-in window movement, resizing, session-transition cleanup, and cross-platform behavior.
- Improved application shutdown feedback and reliability while audio, plug-ins, background work, and windows are being closed.
- Added consistent insert-slot safeguards across manual and CoProducer workflows.
